# DuckDocs Product Context

## Register

product

## Users

Independent consultants, researchers, policy analysts, legal and compliance teams, engineers, and privacy-conscious local teams working with sensitive document libraries. They need to add heterogeneous files, search by meaning, ask grounded questions, verify every answer against evidence, and keep review work close to the source.

## Product Purpose

DuckDocs turns a local document library into a private, evidence-aware intelligence workspace. It is a document tool, not a chat wrapper: ingestion, retrieval, provenance, review, comparison, and export are first-class. The default path runs locally with no account, telemetry, or hidden network calls.

## Brand Personality

Precise, calm, trustworthy. The interface should feel like a seasoned research instrument: dense enough for daily work, quiet enough for long review sessions, and explicit about what the system knows and where it came from.

## Anti-references

Avoid purple AI gradients, cream-and-serif editorial styling, floating dashboard-card grids, opaque chat answers, decorative motion, hidden cloud calls, and any interaction that makes a user hunt for the source behind an answer.

## Design Principles

1. Evidence is an object, not a footnote. Every generated answer exposes a path to its source.
2. Local-first is visible. The product tells users what leaves the machine and keeps the default path offline.
3. Conversation should lead to action. Ask, inspect, annotate, compare, and export remain one connected workflow.
4. Density serves expertise. Defaults are compact, keyboard-friendly, and readable, with a comfortable density option.
5. Honest states build trust. Loading, partial ingestion, low confidence, refusal, and provider failures explain what happened and what to do next.

## Accessibility & Inclusion

WCAG 2.1 AA is a P0 requirement. Keyboard navigation, visible focus, semantic labels, contrast in both themes, reduced-motion support, non-color confidence cues, and a comfortable density mode are required.
